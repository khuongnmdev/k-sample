Explain Reactive vs Imperative State Management

Trong phát triển ứng dụng Angular, cách chúng ta quản lý và đồng bộ trạng thái (state management) có ảnh hưởng cực kỳ quan trọng tới hiệu suất, tính dễ đọc và bảo trì của mã nguồn. Trang này so sánh 3 cách tiếp cận phổ biến khi xây dựng tính năng tìm kiếm và lọc danh mục sản phẩm: Imperative State (Mệnh lệnh truyền thống), Observable State (Phản ứng luồng RxJS), và Signal State (Phản ứng hạt mịn Signal).

1. Imperative State (Lập trình Mệnh lệnh)

Tự tay bắt sự kiện, cập nhật giá trị biến, và trực tiếp gọi hàm cập nhật logic kết quả.

2. Observable State (Lập trình Phản ứng - RxJS)

Biểu diễn các nguồn dữ liệu đầu vào dưới dạng luồng dữ liệu (Streams). Phối hợp các luồng với toán tử và tự động cập nhật ngoài giao diện nhờ AsyncPipe.

3. Signal State (Lập trình Phản ứng - Angular Signals)

Cách tiếp cận khuyến nghị cho Angular hiện đại. Sử dụng cơ chế tự động ghi nhận phụ thuộc cực kỳ tối ưu thông qua computed signal.
