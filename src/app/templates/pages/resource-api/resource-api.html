Resource APIs: resource - rxResource - httpResource

resource() biến "dữ liệu bất đồng bộ" thành một nhóm signal gói sẵn: value(), status(), error(), isLoading() - kèm reload() và tự hủy request cũ khi params đổi. Demo: đổi user để loader tự chạy lại, thử id không tồn tại để thấy trạng thái error.
⚠️ Nhóm API này vẫn đang ở trạng thái experimental (tính đến Angular 21).

status(): {{ user.status() }} - isLoading(): {{ user.isLoading() }}

@if (user.isLoading()) {

} @else if (user.error()) {

error(): {{ user.error()?.message }}

} @else if (user.hasValue()) {

value(): user {{ user.value().name }} - mã code {{ user.value().code }}

}

httpResource với API thật (swapi.info)

Cùng pattern nhưng gọi HTTP thật: httpResource nhận một hàm URL reactive.
personId đổi: request mới tự bắn, request cũ tự hủy - mở Network tab để xem.
Response bị interceptor delay thêm 1.2s để loading state kịp hiển thị (swapi thật chỉ ~150ms).
Person 9999 không tồn tại: server trả 404 thật, đọc được qua statusCode().
