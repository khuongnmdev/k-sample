Signal Advanced: linkedSignal - Custom Equality - Router Input Binding

Ba công cụ Signal cần biết sau khi đã vững signal / computed / effect.
linkedSignal: state dẫn xuất như computed, nhưng user GHI ĐÈ được.
equal: dạy cho signal biết thế nào là "giá trị không đổi" để khỏi notify thừa.
withComponentInputBinding: param trên URL tự chảy vào input(), không cần ActivatedRoute.

1. linkedSignal - Betslip

linkedSignal = signal GHI ĐƯỢC (.set) + TỰ TÍNH LẠI khi nguồn đổi - con lai giữa signal và computed.
Trong demo, cờ "cần xác nhận odds" là một linkedSignal với NGUỒN là odds (input từ parent, server đổi random mỗi 5 giây):
1. Odds đổi → công thức tự chạy lại → cờ bật true → nút Đặt cược bị khóa.
2. User bấm "Chấp nhận odds mới" → .set(false) ghi đè → mở khóa.
3. Stake là signal thường - odds đổi KHÔNG đụng tới tiền user đang nhập.
Thử: nhập stake, chờ 5 giây cho odds đổi, quan sát nút Đặt cược và stake.

2. Custom Equality

Hai signal cùng chứa object user. Khác nhau duy nhất: một cái có equal so sánh nội dung.
"Server trả y hệt": object MỚI nhưng nội dung cũ - signal mặc định vẫn notify (thừa), signal có equal thì im lặng.
"Tăng tuổi": nội dung đổi thật - cả hai cùng notify.

signal mặc định notify: {{ defaultNotifyCount() }}
signal có equal notify: {{ smartNotifyCount() }}

(user hiện tại: {{ smartUser().name }} - {{ smartUser().age }} tuổi)

3. withComponentInputBinding

Bấm nút để đổi query param trên URL (nhìn thanh địa chỉ).
Giá trị chảy thẳng vào input() của component - không ActivatedRoute, không subscribe.
Use case: filter / tab / voucher share được qua URL, F5 không mất state.

voucher() = {{ voucher() || '(chưa có)' }}
